⚙️ Настройки системы

Основные параметры PlayPC и юридический текст.

Вход администратора проверяется сервером через жёстко заданный пароль AdminPlayPC2026. Поле нового пароля сохранено в интерфейсе для совместимости с системой настроек; текущий server.js использует фиксированный ADMIN_PASSWORD.
Для фактической смены пароля также потребуется изменить ADMIN_PASSWORD в server.js.
